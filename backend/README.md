# Backend

PHP 8.3 API built with Slim 4 and PDO (PostgreSQL).

The application has not been scaffolded yet. The planned layout is:

```
public/        HTTP entrypoint
src/           Application code (controllers, services, repositories)
config/        Routes and container settings
migrations/    Database migrations (Phinx)
seeds/         Seed data (categories, badges)
tests/         PHPUnit tests
```

See the root [README](../README.md) for the project overview.
