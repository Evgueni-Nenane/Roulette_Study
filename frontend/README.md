# Frontend

React single-page application built with TypeScript and Vite.

The application has not been scaffolded yet. The planned layout is:

```
src/
  pages/       Route-level components
  components/  Reusable UI components
  api/         API client and query hooks
  hooks/       Shared React hooks
  styles/      Tailwind entrypoint and global styles
```

See the root [README](../README.md) for the project overview.
